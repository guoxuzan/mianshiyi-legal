面试易

BOSS AI助手

面试易的浏览器扩展。在你打开的 BOSS 直聘求职网页上，筛选职位、对照简历做匹配，并在你主动点击「开始」后辅助打招呼。
不是 BOSS 直聘官方产品。运营主体：北京明易科技有限公司。

Chrome / Edge。未开通可试用 30 次。登录面试易即可用，无需在扩展里配置大模型或 API Key。

能做什么

  • 按你设定的条件筛选职位（岗位名、公司、猎头、外包、已聊、不活跃等）
  • 由面试易服务端根据岗位与简历生成个性化招呼语
  • 你点「开始」后按本轮数量辅助发送，到量自动停
  • 本机与账号同步最近投递记录

怎么用

  1. 从 Chrome 网上应用店添加本扩展，或在已登录的面试易账户中加载扩展
  2. 打开扩展，登录面试易（网页授权，不用配模型）
  3. 打开 BOSS 直聘职位页，保持扩展开启
  4. 设好筛选与本轮数量，由你点击开始
